# 21st Century Developer Standards Skill

This skill enforces 21st-century pair programming, clean code architecture, and empirical runtime verification.

## Core Rules
1. **Never Guess Code Logic or Paths**: Always inspect authoritative source code using grep search and file viewing tools before making edits.
2. **Empirical Verification Required**: Never claim success without building or running verification tools (e.g. Next.js dev compiler checks, tests, page content verification).
3. **No Superficial Symptom Patches**: Resolve underlying root causes rather than hiding errors with dummy fallbacks or swallowing exceptions.
4. **Preserve API Contracts**: Update all invocation sites when function signatures or data contracts change.
5. **Modern Stack Best Practices**: Leverage TypeScript strict typing, Next.js App Router patterns, modular SCSS/CSS variables, and SEO optimization.
