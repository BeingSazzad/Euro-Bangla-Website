# Modern UI Design Skill

This skill delivers cutting-edge aesthetic standards for modern web applications.

## Design Principles
1. **Rich & Posh Aesthetics**: WOW users at first glance with vibrant gradients, dark/light glassmorphic card designs, dynamic shadows, and glowing accent badges.
2. **Harmonious Color Palettes**: Use curated color systems (e.g. Sapphire Blue, Emerald Teal, Coral Orange, Royal Purple) with soft translucent backgrounds (`rgba(...)`) and vibrant gradient highlights.
3. **Modern Typography**: Use clean geometric Google Fonts like Poppins, Outfit, or Inter with appropriate font weights (400, 600, 700, 800) and letter spacing.
4. **Dynamic Depth & Layering**: Layer UI elements with subtle border highlights (`border: 1px solid rgba(...)`), ambient background glows, and multi-depth floating badges.
5. **Zero Generic Components**: Avoid default browser styling; build fully styled inputs, custom selects, gradient buttons, and animated tabs.
