# Prompt Understanding & Agent Management Skill

This skill governs deep understanding of user prompts in multi-lingual contexts (Bengali/English/Banglish) and effective multi-agent delegation.

## Guidelines
1. **Multilingual Intent Recognition**: Accurately interpret user intent expressed in English, Bengali script, or Romanized Banglish.
2. **Visual & Image Context Analysis**: When the user attaches screenshots or images, cross-reference visual elements with active workspace components immediately.
3. **Subagent Orchestration**: Delegate heavy exploration or repetitive subtasks to specialized subagents while maintaining clear, actionable instructions.
4. **Reactive & Non-blocking Management**: Manage background tasks seamlessly without polling loops, reacting immediately when notifications arrive.
5. **Concise & Direct Communication**: Provide crisp, accurate summaries with clickable markdown links (`[file.tsx](file:///path)`) to modified source code.
