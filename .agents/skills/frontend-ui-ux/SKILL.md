# Frontend UI/UX Excellence Skill

This skill provides comprehensive instructions for designing and implementing world-class user interfaces and exceptional user experiences.

## Core UX Principles
1. **Visual Hierarchy & Contrast**: Emphasize key actions with bold typography, distinct color weight, and proper white space spacing.
2. **Predictable Interaction & Feedback**: Provide instant interactive visual feedback (hover, focus, active, loading states) for every clickable element.
3. **Accessibility & Usability**: Ensure clear color contrast ratios, screen-reader semantic HTML tags, keyboard navigation (`tabindex`, `aria-` attributes), and touch targets of at least 44x44px.
4. **Responsive Layout Grid**: Design fluid layouts scaling smoothly from small mobile screens up to 4K ultra-wide monitors using Flexbox, CSS Grid, and responsive breakpoints.
5. **Polished Micro-Interactions**: Use smooth CSS transitions (`cubic-bezier(0.4, 0, 0.2, 1)`) for card hover elevation, button clicks, and modal popups.
